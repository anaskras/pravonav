# PravoNav

Информационный навигатор по официальным нормам РФ в сфере защиты прав потребителей.

По бытовому вопросу пользователя система находит релевантные фрагменты
официальных источников и показывает текст, источник и сведения о редакции.

> Информационный прототип, не юридическая консультация.

## Какую задачу решает?

Потребителю сложно найти применимую норму в первоисточниках и отличить похожие
сценарии. PravoNav ищет по небольшому корпусу официальных документов и
возвращает проверяемые фрагменты со ссылками на источник.

Текущий сценарий V0.1 — возврат товара надлежащего качества. Дистанционная
продажа, товар с недостатком и услуги пока не входят в корпус.

## Источники

- `pravo.gov.ru` — официальное опубликование нормативных актов
- Материалы Роспотребнадзора — при необходимости

Каждый фрагмент хранит текст, структуру документа, URL, дату доступа,
дату редакции или доступную информацию о версии источника.

## Технологии и оценка

- Python
- BM25 — baseline retrieval
- Корпус в JSONL: `document → article → chunk`
- Ручная разметка бытовых вопросов
- Метрики: Recall@3/5, MRR@5, nDCG@5
- Анализ ошибок: покрытие корпуса, chunking, lexical mismatch, intent, ranking

Dense retrieval, reranking, векторные БД и LLM добавляются только после
измерения baseline и при наличии конкретной гипотезы об улучшении.

## Развитие

| Версия | Цель |
|---|---|
| V0.1 | Retrieval baseline: официальный корпус, chunks, BM25, разметка и оценка |
| V0.2 | Grounded-информационный ответ с цитатами и отказом при недостатке оснований |
| V0.3 | Информационная навигация: уточнение контекста и возможные действия с источниками |
| V1.0 | Пользовательский интерфейс поверх проверенного ядра; первый кандидат — Telegram-бот |

Расширение на другие потребительские сценарии и сферы — отдельное дальнейшее
развитие после проверки подхода на первом ограниченном домене.

## Ограничения

PravoNav не устанавливает факты конкретной ситуации, не прогнозирует исход
спора и не заменяет юридическую консультацию. Если в корпусе нет достаточного
официального основания или сценарий не поддерживается, система должна явно
обозначить это ограничение.
